ONESHOT

The stream kit's OBS setup, for this folder:

The scene collection

Five scenes: Starting Soon, Game, BRB, Ending, and Watch a match (the game itself watching a live match a little behind). In OBS: Scene Collection → Import, pick the file, then switch to oneshot. In the Game scene, open Game Window and pick the oneshot window.

Each overlay on its own

In OBS: add a Browser source, paste the link into its URL field (not "Local file", which drops the part after ?), and set the width and height shown.
